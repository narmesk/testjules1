# XIAO ESP32C3 Web Server Projesi

Bu proje, Seeed Studio XIAO ESP32C3 geliştirme kartı üzerinde çalışan, web sunucusu (web server) tabanlı bir kod projesidir.

## Proje Yapısı

Proje dosyaları `xiao_esp32c3_webserver/` klasörü altında tutulacaktır. Arduino standartlarına uygun olarak ana dosya `xiao_esp32c3_webserver.ino` olarak adlandırılmıştır.

## Geliştirme Süreci

Kodu parça parça, deneye deneye ve her aşamada doğrulayarak geliştireceğiz.

### Kodunuzu Nasıl Ekleyebilirsiniz?

Kodunuzu veya dosyalarınızı bana şu şekillerde iletebilirsiniz:
1. **Mesaj olarak doğrudan paylaşmak:** Kod bloklarını buraya yapıştırabilirsiniz, ben de bunları ilgili dosyalara (örneğin `.ino` dosyasına veya `data/` klasöründeki HTML/CSS/JS dosyalarına) yerleştiririm.
2. **Parçalar halinde belirtmek:** "Şu fonksiyonu ekleyelim", "Şu kütüphaneyi kuralım" şeklinde yönlendirerek adım adım ilerleyebiliriz.

Lütfen eklemek istediğiniz ilk kod parçasını paylaşın!
