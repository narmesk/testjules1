# Deneme Proje (Delphi 12)

Bu proje, Embarcadero® Delphi 12 (Version 29.0.51961.7529) kullanılarak oluşturulmuş basit bir konsol uygulaması denemesidir.

## İçerik
- `DenemeProje.dpr`: Ana proje dosyası.

## Nasıl Çalıştırılır?
1. Delphi 12 IDE'sini açın.
2. `DenemeProje.dpr` dosyasını açın.
3. `F9` tuşuna basarak projeyi derleyip çalıştırın.
